## 🚀 Featured project

### [PaperDeck](https://github.com/shrutigajre150/paperdeck) · [Live demo](https://paperdeck-shruti.streamlit.app)
Ask questions about research papers and get page-cited answers plus an auto-generated slide deck.

- **Hybrid retrieval:** BM25 + MiniLM embeddings in FAISS with Reciprocal Rank Fusion; **1.000 MRR** and **100% Hit@1** on a hand-labeled evaluation set, at about 16 ms per query
- **Grounded answers:** mandatory [paper, page] citations, a relevance cutoff, and automatic removal of unretrieved citations; **100% valid citations (35/35)** and all out-of-scope questions declined
- **Slides:** an LLM slide agent returns structured JSON rendered by python-pptx into a cited deck
- **Stack:** Python · FAISS · BM25 · Sentence-Transformers · OpenAI API · python-pptx · Streamlit
